# Cash Flow Gap Detector

## Purpose
This application will help users identify whether upcoming bills could
exceed their available money before their next paycheck. It will forecast
daily balances over a 30-day period using manually entered information.

## Essential Features
- Save a starting balance and forecast start date.
- Add, view, edit, and delete scheduled income and expenses.
- Display a 30-day table of projected daily closing balances.
- Highlight negative balances and show the first shortfall date,
  lowest balance, additional funds needed, and ending balance.

## Technology
- Frontend: HTML, CSS, and JavaScript
- Backend: Node.js and Express
- Database: SQLite
- Money stored and calculated as integer cents

## Project Scope
The application will use fictional data and USD only.
Transactions on the same date will be combined into daily totals.

Bank connections, real payments, automatic recurring transactions,
authentication, and multiple currencies are outside the scope.
A balance chart may be added after the essential features are tested.
